# jsPDF

- **Library Name:** jsPDF
- **Version:** 4.2.1
- **Source:** https://github.com/parallax/jsPDF
- **Purpose:** PDF export/generation in CookieRay admin dashboard
- **License:** MIT
- **Note:** This is jsPDF (PDF document generator), not Mozilla PDF.js (PDF viewer).

The WordPress.org review referenced https://github.com/mozilla/pdf.js which is a different library for viewing PDFs. jsPDF 4.2.1 is the current stable release and is used to generate PDF exports of cookie consent reports.
